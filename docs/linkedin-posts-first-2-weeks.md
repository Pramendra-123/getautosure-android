## Post 2 · Fri 27 Nov · Check-engine light: steady or flashing?

**Visual:** a simple 2-panel card, "STEADY = get it checked soon" / "FLASHING = slow down, get help now" (I can make this)

> The check-engine light came on. Do you keep driving?
>
> It depends on one thing most people don't notice: is it steady or flashing?
>
> 🟠 Steady: the car has stored a fault. It's usually safe to drive gently, but get it checked within a few days. Common causes include a loose fuel cap, an oxygen sensor or worn spark plugs.
>
> 🔴 Flashing: the engine is actively misfiring. Unburnt fuel can overheat and ruin the catalytic converter, which costs ₹8,000–₹35,000 or more to replace. Slow down and get help.
>
> The light only tells you something is wrong. The fault code tells you what. Plug in an OBD2 scanner and you'll know before you reach the workshop.
>
> Save this for the next time it lights up.
>
> #CheckEngineLight #CarTips #CarMaintenance #India

## Post 3 · Mon 30 Nov · Myth: "clearing the code fixes the problem"

**Visual:** a text card, "MYTH: Clearing the fault code fixes the car. ❌"

> Myth: "The mechanic cleared the code, so the problem is fixed."
>
> Clearing a fault code turns the light off. It doesn't fix anything.
>
> The car re-checks itself over the next few drives. If the problem is still there, the code comes back, often within a week.
>
> This matters most when you're buying a used car. A seller can clear the codes an hour before you arrive, and the dashboard will look perfect.
>
> But the car's computer still remembers: how many kilometres and warm-ups since the codes were last cleared, and which self-checks haven't finished yet. A scan shows you all of it.
>
> Before you pay a token amount, ask one question: "When were the codes last cleared?"
>
> #UsedCars #CarBuying #CarTips #India
