Today the scan's best findings (cleared codes, odometer, a warmed-up engine) appear only on the last step, below the price, where they look like extra detail. What changes
  • A new step straight after the scan: Seller check. It uses checks the app already does, so no new detection is needed.
  • Every check shows one of three results: red flag, ask the seller, or clear. "Not available" is shown openly when the car doesn't report it, never as a pass.
  • In the report and PDF, the seller check moves above the price. RTO moves below.
  • The start screen copy becomes: "Find out what the seller might be hiding: cleared fault codes, a rolled-back odometer, an engine warmed up before you arrived."
  • The same line can lead the used-car section of the website.
